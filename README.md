# Simple RAG Teaching Project

A minimal **Retrieval-Augmented Generation (RAG)** system built from scratch in Python. Designed for students who want to understand how RAG works step by step — no LangChain, no API keys, everything runs locally with Ollama.

## What is RAG?

Large language models (LLMs) know a lot, but they don't know *your* documents. RAG fixes this by:

1. **Loading** your documents
2. **Chunking** them into smaller pieces
3. **Embedding** each chunk into a vector (a list of numbers that captures meaning)
4. **Storing** those vectors in a searchable index
5. When a user asks a question, **retrieving** the most relevant chunks
6. **Generating** an answer using the LLM, grounded in the retrieved context

```
Documents → Chunk → Embed → Store          (ingest.py)
                              ↓
Question → Embed → Retrieve → Prompt + LLM → Answer   (ask.py)
```

## Prerequisites

### 1. Install Ollama

Download and install Ollama from [https://ollama.com](https://ollama.com).

After installation, pull the required models:

```bash
ollama pull nomic-embed-text
ollama pull llama3.2
```

- `nomic-embed-text` — converts text into embedding vectors (~274 MB)
- `llama3.2` — a small chat model (3B parameters, ~2 GB) that runs on most laptops

Verify Ollama is running:

```bash
ollama list
```

### 2. Install Python dependencies

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

## Usage

### Step 1: Build the index

```bash
python ingest.py
```

This loads all `.txt` files from `data/`, splits them into chunks, embeds each chunk, and saves the index to the `index/` folder. Re-run it whenever you add or change documents.

### Step 2: Ask questions

```bash
# Single question
python ask.py "Which planet is the largest?"

# Interactive mode (type questions, 'quit' to exit)
python ask.py

# Retrieve more context chunks
python ask.py "Tell me about computers" --top-k 5

# Hide the retrieved chunks and scores
python ask.py "What is photosynthesis?" --quiet
```

## How it works (for students)

| Step | What it does | Where |
|------|-------------|-------|
| Load | Read `.txt` documents from disk | `ingest.py` |
| Chunk | Split text into overlapping pieces | `rag.chunk_text()` |
| Embed | Convert text to vectors with Ollama | `rag.embed()` |
| Store | Save vectors + metadata to `index/` | `rag.save_index()` |
| Retrieve | Find relevant chunks via cosine similarity | `rag.retrieve()` |
| Generate | Answer with LLM grounded in context | `rag.generate_answer()` |

Read the files in this order: `rag.py` → `ingest.py` → `ask.py`. Every function has a short docstring explaining its role in the pipeline.

## Exercises for students

1. Add your own `.txt` document to `data/`, re-run `python ingest.py`, and ask questions about it
2. Change `CHUNK_SIZE` and `OVERLAP` in `rag.py` — observe how retrieval quality changes
3. Compare answers with `--top-k 1` vs `--top-k 5`
4. Try a different Ollama chat model: pull it (`ollama pull mistral`) and change `CHAT_MODEL` in `rag.py`
5. Print the similarity scores for a relevant vs an irrelevant question — what threshold separates them?

## Troubleshooting

| Problem | Solution |
|---------|----------|
| `Cannot connect to Ollama` | Make sure Ollama is running: `ollama serve` |
| `Missing Ollama models` | Pull them: `ollama pull nomic-embed-text` and `ollama pull llama3.2` |
| `No index found` | Run `python ingest.py` before `python ask.py` |
| Slow first response | The model loads into memory on first use; subsequent calls are faster |
| Out of memory / disk | Try a smaller model (`ollama pull phi3`) and update `CHAT_MODEL` in `rag.py` |
